# نظام كشف التصيد الاحتيالي عبر تحليل عناوين URL
## شرح مشروع التخرج

## المقدمة

مرحباً بكم في عرض مشروع التخرج حول نظام كشف التصيد الاحتيالي. يركز هذا المشروع على تحليل عناوين URL واكتشاف محاولات التصيد الاحتيالي باستخدام تقنيات الذكاء الاصطناعي والتعلم الآلي. سنقوم بشرح الآليات الرئيسية لتحليل الروابط وكيفية اكتشاف الروابط الضارة.

## نظرة عامة على النظام

نظامنا يعمل على تحليل عناوين URL من خلال مجموعة من الخطوات:

1. **تحليل بنية الرابط**: فحص أجزاء العنوان مثل النطاق والمسار وسلسلة الاستعلام.
2. **استخراج الخصائص**: تحليل أكثر من 25 خاصية للرابط الواحد.
3. **التحقق من السمعة**: الاتصال بقواعد بيانات أمنية خارجية للتحقق من سمعة الرابط.
4. **حساب درجة المخاطر**: تقييم احتمالية كون الرابط تصيداً احتيالياً على مقياس من 0 إلى 10.
5. **إصدار الحكم النهائي**: تصنيف الرابط كآمن، مشبوه، أو تصيد احتيالي.

## الوظائف الرئيسية

### 1. تحليل عنوان URL (`analyze_url`)

هذه هي الوظيفة الرئيسية التي تنسق عملية التحليل بأكملها:

```python

    1. تحليل والتحقق من صحة URL
    2. التحقق من القائمة البيضاء
    3. استخراج الخصائص
    4. فحص السمعة عبر واجهات برمجة التطبيقات (تعمل بالتوازي لزيادة الكفاءة)
    5. حساب الدرجة وتحديد الحكم
    """
```

هذه الوظيفة تبدأ بتحليل بنية العنوان والتحقق من صحته، ثم تقوم بفحص إذا كان العنوان موجوداً في القائمة البيضاء. إذا لم يكن كذلك، تستمر في استخراج الخصائص وإجراء فحوصات السمعة، ثم حساب درجة المخاطر.

### 2. استخراج خصائص العنوان (`extract_url_features`)

تقوم هذه الوظيفة بتحليل مختلف جوانب عنوان URL لاستخراج الخصائص التي قد تشير إلى نشاط تصيد احتيالي:

```python

```

بعض الخصائص المهمة التي نقوم باستخراجها:
- طول العنوان والنطاق
- عدد النطاقات الفرعية
- وجود رموز مشبوهة مثل '@'
- استخدام نطاقات TLD مشبوهة
- استخدام كلمات مفتاحية مرتبطة بالتصيد الاحتيالي
- استخدام خدمات تقصير الروابط
- استخدام بروتوكول HTTPS
- قياس عشوائية (إنتروبيا) النص في أجزاء العنوان

## عملية تصنيف الروابط

بعد حساب درجة المخاطر، نقوم بتصنيف الرابط إلى إحدى الفئات التالية:

```python
def get_url_verdict(score):
    """
    تحول درجة التصيد الرقمية إلى حكم مفهوم للإنسان.
    تصنف هذه الوظيفة عناوين URL إلى فئات مخاطر مختلفة بناءً على درجتها.
    """
    if score <= 0.8: return "Legitimate"
    elif score <= 2.0: return "Potentially Suspicious"
    elif score <= 4.5: return "Suspicious"
    else: return "Phishing"
```

- **مشروع (Legitimate)**: درجة ≤ 0.8
- **مشبوه محتمل (Potentially Suspicious)**: درجة ≤ 2.0
- **مشبوه (Suspicious)**: درجة ≤ 4.5
- **تصيد احتيالي (Phishing)**: درجة > 4.5
